# Mockups

The screens of socle before any window code exists. Each one is an HTML page on `socle.css` and `shell.js` (the title
bar and the sidebar). `socletool mockups [names]` draws them to PNG at 1280 × 800. The design behind them is in
[src/md](../../src/md/README.md).

| Screen | What it shows |
|---|---|
| [overview](overview.png) | the running system, its updates, its space, its pages, the recent changes |
| [apps](apps.png) | the search in the catalogue; an app added, an app of the template removed; the bar of changes |
| [desktop](desktop.png) | a page made from a feature's options; a value changed against the template |
| [review](review.png) | the changes in words, the session that restarts, now or at the next start |
| [preparing](preparing.png) | the stages of an apply, the download and the build |
| [keep](keep.png) | the try: keep the new version, or the system goes back by itself |
| [history](history.png) | the versions, their changes, a version made outside socle, the return |
| [templates](templates.png) | the gallery: socle's templates, the person's own, the community |
| [all-settings](all-settings.png) | any option of the system, its value, the layers that set it |
| [installer](installer.png) | the install from the live image: the disk step |
